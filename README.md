# Curso Avanzado de IA Generativa 2025

Bienvenido al curso más completo y actualizado sobre Inteligencia Artificial Generativa, diseñado para llevar tus conocimientos al siguiente nivel con las tecnologías y técnicas más avanzadas de 2025.

## 🎯 Objetivos del Curso

Este curso te capacitará para:

- Dominar las arquitecturas más avanzadas de LLMs (GPT-5, Claude Sonnet 4.5, Gemini 2.5 Pro)
- Implementar sistemas de IA Agéntica capaces de tomar decisiones autónomas
- Desarrollar aplicaciones empresariales con RAG y Agentic RAG
- Trabajar con modelos multimodales (texto, imagen, audio, video)
- Aplicar técnicas avanzadas de prompt engineering y optimización
- Realizar fine-tuning y personalización de modelos
- Implementar guardrails y sistemas seguros de IA
- Desplegar soluciones de IA generativa en producción
- Comprender y aplicar principios éticos y regulatorios

## 📚 Estructura del Curso

### [Módulo 1: Fundamentos Avanzados y Arquitecturas de Nueva Generación](./modulo01_fundamentos_arquitecturas/)
Evolución de LLMs, GPT-5, Claude Sonnet 4.5, Gemini 2.5 Pro, SLMs, y análisis comparativo.

### [Módulo 2: Inteligencia Artificial Agéntica (Agentic AI)](./modulo02_ia_agentica/)
Fundamentos de agentes, arquitecturas multi-agente, ReAct, AutoGPT, LangGraph, CrewAI.

### [Módulo 3: RAG Avanzado y Agentic RAG](./modulo03_rag_avanzado/)
Técnicas avanzadas de RAG, Hybrid Search, GraphRAG, Agentic RAG, bases de datos vectoriales.

### [Módulo 4: IA Multimodal Avanzada](./modulo04_ia_multimodal/)
Vision-Language Models, generación multimodal, Text-to-Image/Video/Audio, Multimodal RAG.

### [Módulo 5: Prompt Engineering Avanzado y Optimización](./modulo05_prompt_engineering/)
Chain-of-Thought, Tree of Thoughts, Meta-prompting, DSPy, optimización avanzada.

### [Módulo 6: Fine-Tuning y Personalización de Modelos](./modulo06_fine_tuning/)
LoRA, QLoRA, RLHF, DPO, Constitutional AI, modelos verticales especializados.

### [Módulo 7: Modelos Open Source y Deployment](./modulo07_open_source_deployment/)
Llama 4, Mistral, Qwen, Hugging Face avanzado, vLLM, TensorRT-LLM, Ollama.

### [Módulo 8: Frameworks y Desarrollo de Aplicaciones](./modulo08_frameworks_desarrollo/)
LangChain avanzado, LlamaIndex, Semantic Kernel, Haystack, arquitecturas de producción.

### [Módulo 9: Guardrails, Seguridad y Confiabilidad](./modulo09_guardrails_seguridad/)
NeMo Guardrails, detección de alucinaciones, prompt injection, moderación, PII detection.

### [Módulo 10: Observabilidad, Evaluación y MLOps](./modulo10_observabilidad_mlops/)
LangSmith, W&B, métricas de evaluación, A/B testing, CI/CD para IA, LLMOps.

### [Módulo 11: Casos de Uso Empresariales Avanzados](./modulo11_casos_uso_empresariales/)
Asistentes empresariales, automatización, code generation, análisis de documentos.

### [Módulo 12: Sostenibilidad y Eficiencia Energética](./modulo12_sostenibilidad/)
Green AI, carbon footprint, modelos eficientes, edge computing, mejores prácticas.

### [Módulo 13: Aspectos Éticos, Legales y Regulatorios](./modulo13_etica_legal/)
Sesgos, fairness, AI Act, derechos de autor, transparencia, privacidad, GDPR.

### [Módulo 14: Técnicas Avanzadas y Fronteras de Investigación](./modulo14_tecnicas_avanzadas/)
MoE, reasoning models, continual learning, neurosymbolic AI, world models.

### [Módulo 15: Proyecto Final Integrador](./modulo15_proyecto_final/)
Desarrollo de un proyecto completo aplicando múltiples técnicas del curso.

## 💻 Configuración del Entorno

### Instalación Rápida

```bash
# Clonar el repositorio
git clone https://github.com/usuario/curso_avanzado_ia.git
cd curso_avanzado_ia

# Crear entorno virtual
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# Instalar dependencias
pip install -r requirements.txt
```

### Variables de Entorno

Crea un archivo `.env` en la raíz del proyecto:

```env
OPENAI_API_KEY=tu_api_key
ANTHROPIC_API_KEY=tu_api_key
GOOGLE_API_KEY=tu_api_key
HUGGINGFACE_API_KEY=tu_api_key
PINECONE_API_KEY=tu_api_key
```
